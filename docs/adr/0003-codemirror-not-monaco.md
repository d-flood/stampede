# The editor is CodeMirror 6, not Monaco

Editor tabs and Diff tabs are both built on CodeMirror 6.

- The phone is a first-class Device, and CodeMirror works well on touch.
- Its merge package makes the Diff tab the same editor, editable for Uncommitted changes.
- It has an official LSP client.
- Rejected: Monaco, VS Code's editor, despite the best out-of-the-box LSP experience, because it doesn't support mobile browsers.
- Rejected: Wordgard, because it is a rich-text editor library, not a code editor.
