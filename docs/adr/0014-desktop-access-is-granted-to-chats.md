# Desktop access is granted to Chats for the whole Desktop

The user grants a Chat access to one selected Desktop until revoked or the Chat closes; the grant covers all applications and does not override Agent approval rules.

- Desktop work may cross application boundaries.
- Access belongs to the Chat independently of Devices, including when all Devices close.
- A permissive Rig does not automatically authorize Desktop access.
- Rejected: per-application grants, because cross-application tasks become more cumbersome and an allowed browser still exposes a broad environment.
